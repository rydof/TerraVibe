## Overview

**TerraVibe** reimagines *Terraria* as a first-person and over-the-shoulder third-person 3D voxel game while preserving classic Pre-Hardmode mechanics, item IDs, progression tiers, and boss encounters—from your first wooden shelter to defeating the **Wall of Flesh** in the Underworld.

Every world runs on an authoritative background server (`terravibe_server`) ticking a deterministic, Bevy-free simulation (`terravibe_sim`), even in single-player. All 3D block textures, item meshes, armor pieces, sculpted hairstyles, and creature rigs are original procedural voxel art generated by repository scripts, paired with your local Terraria installation's fonts, HUD icons, and audio.

- [x] **Liquids & Hazards**: Cellular water and lava simulation, water + lava obsidian generation, buckets, swimming/drowning, hot-block burning (`Hellstone`), `Obsidian Skull`, `Lava Charm`, and `Obsidian Skin Potion`.
- [x] **Remodeled Weapons, Armor & Set-Bonus FX**: Tiered progression from Copper → Iron → Silver → Gold → Shadow/Demonite → Molten gear, authentic weapon scaling & swing/thrust/stab/fire animations (`ShortswordStab`, `SpearThrust`, `GunFire`, `WhipSnap`), elemental swing arc particles, metallic armor sheen, and Shadow/Molten emissive pulses + set-bonus particles.

- [x] **Town NPCs, Housing & Economy**: 3D flood-fill room validation, Guide advice chain, Merchant shop (`p/g/s/c` coin denominations & 1/5th sell-back), Nurse, Arms Dealer, Old Man, and an integrated Inventory `[Housing]` tab with room query (`?`) and NPC banners.
- [x] **Critters & Bug Net**: Calm, killable critters (`Bunny`, `Bird`, `Squirrel`, `CaveCritter`) that can be caught with the `Bug Net` (`ItemId(1991)`) and released as live critters.

## Architecture

TerraVibe is a 4-crate Rust workspace (`edition = "2024"`, `resolver = "3"`) that enforces a strict boundary between game simulation and the rendering engine:

```text
┌────────────────────────────────────────────────────────┐
│                   terravibe_client                     │
│  Bevy 0.20: 3D Renderer, WESL Shaders, Audio, HUD, QA  │
└───────────────▲────────────────────────▲───────────────┘
                │ ClientMsg              │ ServerMsg
┌───────────────▼────────────────────────▼───────────────┐
│                   terravibe_server                     │
│  Authoritative Server Thread, World State, .bak Saves  │
└───────────────────────────▲────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│                    terravibe_sim                       │
│  Pure Simulation: Physics, Worldgen, Combat, Boss AI   │
└────────────────────────────────────────────────────────┘
```

| Crate | Path | Responsibility |
| :--- | :--- | :--- |
| `terravibe_sim` | [`crates/sim`](crates/sim) | Deterministic simulation: 32³ RLE/bitset chunks, worldgen, physics, combat, crafting, housing, enemy & boss AI |
| `terravibe_server` | [`crates/server`](crates/server) | Authoritative background server loop, chunk streaming, server-side validation, atomic `.bak` save persistence |
| `terravibe_assets` | [`crates/assets`](crates/assets) | `.vox` model and texture loader plus local XNB/XWB extractors |
| `terravibe_client` | [`crates/client`](crates/client) | Bevy 0.20 frontend, greedy chunk mesher, 3D lighting shaders, procedural animations, HUD/menus, audio, bench/QA harnesses |

### Rendering & Async Pipeline

- **Greedy `Texture2DArray` Chunk Mesher**: Merges coplanar adjacent voxel faces (`crates/client/src/art/chunk_mesh.rs`) with per-vertex ambient occlusion, reducing terrain quad counts by ~38%.
- **3D Cellular Lighting Volume**: Sky and block light flood-fill packed into a `34³` GPU 3D texture sampled via `textureSampleLevel` in `crates/client/src/light/shaders/chunk_light.wesl`, with compile-time `@if(MAY_DISCARD)` preserving GPU Early-Z on opaque terrain.
- **Off-Main-Thread Chunk Prep**: `LightInput` packing, `ChunkMeshInput` packing, and static block-model batching run on Bevy's async compute pool while tree canopies remain GPU-instanced and main-thread GPU uploads are frame-budgeted.

### Architectural Invariants

1. `crates/sim` and `crates/server` have **zero** dependencies on Bevy, rendering, or audio.
2. `Settings` and `InputBindings` remain `Copy`.
3. Every in-world dropped item renders as a 3D `.vox` model (`DropVisual::Model`), never a 2D billboard.
4. Extracted Terraria assets live in gitignored `assets/terraria-pack/` for personal use only and are never committed.

## Quickstart

### 1. Prerequisites

- **Rust** toolchain (`cargo`, `rustc` supporting Edition 2024)
- **Python 3** (for procedural art generation and validation)
- **Local Terraria installation** (for personal-use font, HUD icon, and audio extraction)

### 2. Extract Local Terraria Assets

```sh
tools/install-terraria-assets.sh                    # auto-detects Steam install
tools/install-terraria-assets.sh --terraria-dir /path/to/Terraria
```

Runtime asset search order: `--assets-dir PATH` → `TERRAVIBE_ASSETS_DIR` → `assets/terraria-pack/` → `<exe dir>/assets/` → Steam/Terraria install (`--terraria-dir` or `TERRAVIBE_TERRARIA_DIR`).

### 3. Build & Run

```sh
cargo build --release
target/release/terravibe
```

Set `TERRAVIBE_MONITOR` to a monitor name substring to pin automated benchmark/QA windows (defaults to internal panels `eDP`/`LVDS`/`DSI`). See [`docs/reference/game-data.md`](docs/reference/game-data.md) for all CLI flags and environment variables.
